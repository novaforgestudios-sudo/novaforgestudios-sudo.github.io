FREE GITHUB PAGES SETUP:
1. Create a GitHub account.
2. Create a PUBLIC repository named:
   novaforgestudios.github.io
3. Upload all files from this folder, keeping the assets folder.
4. Open Settings > Pages.
5. Select Deploy from a branch, choose main and /root.
6. Save.
7. Your free site will be:
   https://novaforgestudios.github.io

Before publishing, replace contact@novaforgestudios.com in index.html with your real business email if needed.
